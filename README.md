# Pickle Studio — 블로(Vrew) 스타일 웹 영상편집기 (2차 프로토타입)

PC·모바일 겸용 웹 영상편집기 2차 프로토타입입니다. 설치 없이 브라우저에서 바로 편집하고,
유튜브 롱폼(16:9)과 숏폼(9:16)을 한 번에 오가며, AI 성우·감정별 효과음·다국어 자막까지 한 화면에서 다룹니다.

- **배포 주소**: https://pickle-video-studio.vercel.app (Vercel · `main` 푸시 시 자동 재배포)
- **저장소**: https://github.com/nicehama/pickle-video-studio
- **스택**: Next.js 14 App Router · TypeScript · Tailwind CSS · Canvas 2D · Web Audio · Web Speech · MediaRecorder

## 실제로 동작하는 것 (1·2차)

### 1. PC · 모바일 반응형 편집 화면
- **PC(1024px+)**: 좌측 미디어 패널 + 중앙 프리뷰 캔버스 + 우측 도구(자막·성우·효과음) + 하단 5트랙 타임라인 + 단축키 안내.
- **모바일**: 상단 프리뷰 + 탭형 도구 + 접이식 타임라인. 클립 이동·트림 손잡이는 눈에 보이는 선은 얇지만 **터치 영역 44×44px**로 잡혀 있습니다.
- 단축키(PC): `Space` 재생/일시정지, `S` 재생 헤드에서 분할, `Delete` 선택 클립 삭제, `⌘/Ctrl+Z` 실행 취소, `⇧⌘Z` 다시 실행, `←/→` 0.5초 이동.

### 2. 롱폼(16:9) ↔ 숏폼(9:16) 원클릭 전환
- 상단 세그먼트로 즉시 전환. 클립·자막·시간 데이터는 그대로 유지되고 프리뷰 캔버스 해상도만 1280×720 ↔ 720×1280으로 바뀝니다.
- 숏폼에서는 **유튜브 쇼츠 안전영역 오버레이**(우측 버튼 영역 / 하단 설명·캡션 / 상단 상태바)를 켜고 끌 수 있습니다. 오버레이는 내보낼 때 자동으로 빠집니다.

### 3. 실제로 만질 수 있는 편집기
- 로컬 영상·오디오 업로드(파일은 브라우저 안에만 머묾) 또는 **내장 샘플 씬 6종**을 눌러 바로 편집 시작.
- 재생/일시정지/정지, 재생 헤드 이동, **컷 분할(S)**, **트림(양끝 핸들)**, **클립 이동(스냅 지원)**, **삭제**, **실행 취소/다시 실행**.
- 샘플과 절차적 씬은 `lib/renderer.ts`의 한 렌더러로 그려 프리뷰와 내보내기 결과가 같습니다.

### 4. AI 성우(TTS) 스튜디오
- 감정 톤 4종(차분함 · 활기참 · 다큐 · 쇼츠 텐션)이 속도/피치/음량 프리셋을 함께 바꿉니다.
- **호흡·쉼표 삽입**: `<0.5s>` 토큰을 넣으면 브라우저 음성이라도 문장 사이에 실제 침묵이 들어갑니다(SSML 미지원 우회).
- 속도·피치·강세 슬라이더, 예상 길이 계산, 미리듣기, 타임라인 삽입(성우 트랙).
- **실제 오디오로 재생**: 미리듣기·타임라인 삽입 시 `/api/tts`(ElevenLabs)에서 받은 MP3를 디코딩해 **타임라인 재생과 WebM 내보내기에 실제 성우 음성으로** 섞습니다. 클립 길이는 생성된 오디오 길이로 맞춰집니다.
- **캐시 재사용**: 같은 문장·같은 톤·같은 속도는 IndexedDB에 저장된 오디오를 다시 쓰므로 크레딧이 다시 나가지 않습니다(새로고침 후에도 유지).
- **iOS Safari·인앱 브라우저**: 재생 버튼 클릭 핸들러 안에서 동기적으로 `AudioContext.resume()` + 무음 버퍼 + `<audio>` 언락을 수행하고, 그래도 컨텍스트가 멈춰 있으면 안내 토스트를 띄웁니다(아이폰 측면 무음 스위치 안내 포함).
- **어댑터 구조**: `GET /api/tts`가 `browser | elevenlabs | openai`를 알려 주고, ElevenLabs가 402/422를 돌려주면 **다른 음성(premade)·모델로 자동 재시도**한 뒤 OpenAI → 브라우저 음성 순으로 내려갑니다. 실패 사유는 화면에 표시됩니다. `GET /api/tts?diag=1`로 연결 상태를 확인할 수 있습니다.

### 5. 상황·감정 세분화 효과음(SFX) 스튜디오
- 3단 태그: **카테고리(동물/자연/생활/교통/기계/인간/추상) × 감정·뉘앙스(반가움/경계/놀람/긴장/편안/웃김/슬픔) × 강도·거리감(가까이·강하게/보통/멀리·약하게)**.
- 한 줄 프롬프트("강아지가 반가워해서 가까이서 짖는 소리")를 태그로 **자동 해석**하고, 같은 태그에서 결정적 난수로 **변주 4종**을 만듭니다.
- **ElevenLabs 사운드 이펙트 API 기본 연결**: 미리듣기·타임라인 삽입을 누르면 `/api/sfx`로 실제 효과음을 생성하고, 그 오디오가 타임라인 재생·WebM 내보내기에 그대로 들어갑니다. 실패·한도 초과일 때만 Web Audio 합성으로 폴백합니다(화면에 안내).
- 같은 태그·프롬프트·변주는 IndexedDB 캐시를 재사용합니다(크레딧 절약). 성우 발화 구간과 겹치면 자동 **−8dB** 덕킹되고 타임라인에 `DUCK` 배지가 붙습니다.

### 6. AI 자막 & 다국어 번역
- 줄별 편집, 숏폼(노랑 ExtraBold 1줄)/롱폼(흰색 하단 2줄) 프리셋, 글자 수 초과 경고, **2줄 나누기** 버튼.
- 한국어 원문 → 영어·일본어·스페인어 번역(`/api/translate`). 키가 없을 때는 표본 문장 사전으로 동작하고, 그 외 문장은 "API 키 필요"로 표시합니다.
- 줄마다 **±150ms 싱크 조정**과 오프셋 배지.
- 언어별 폰트 폴백 스택(일본어는 Hiragino/Noto Sans JP로 자동 폴백) 표시.
- **SRT 4개 언어 다운로드**(실제 `.srt` 파일 생성) — 자막 패널과 내보내기 모달 양쪽에서 가능.

### 7. 자동 저장 & 복원 (IndexedDB)
- 프로젝트(클립·자막·성우·효과음·BGM·제목·비율·프레이밍)를 **IndexedDB에 0.6초 디바운스로 자동 저장**합니다. 새로고침·재접속하면 그대로 이어서 편집합니다.
- 업로드한 **영상·오디오 파일도 IndexedDB에 함께 담아** 복원합니다(용량 초과 시 그 파일만 다시 올리라는 안내). IndexedDB를 못 쓰는 환경에서는 localStorage로 프로젝트만 저장합니다.
- 헤더에 **`저장됨 12:34` / `저장 중…` / `저장 실패`** 상태를 표시하고, 누르면 즉시 저장합니다.
- **`새 프로젝트`** 버튼 → 빈 프로젝트 또는 샘플 프로젝트로 새로 시작(저장본 교체). 편집 중인 내용을 지우기 전에 확인창을 띄웁니다.

### 8. 16:9 ↔ 9:16 비율별 프레이밍 (Crop x·y·scale 따로 저장)
- 영상 클립마다 `framing: { "16:9": { x, y, scale }, "9:16": { x, y, scale } }`를 **따로** 저장합니다. 원본 파일은 건드리지 않습니다.
- 프리뷰 상단 **`🎯 프레이밍`**을 켜고 슬라이더(좌우·상하·확대 1~3배)를 움직이거나, **프리뷰를 직접 드래그**하면 지금 보고 있는 비율에만 적용됩니다.
- 우측 클립 인스펙터에서도 같은 값을 조정할 수 있고, **`16:9 값 복사`**로 반대 비율 값을 가져올 수 있습니다.
- 꽉 채움(cover) 기준이라 빈 여백이 생기지 않도록 넘치는 만큼만 이동합니다. 내보내기에도 같은 프레이밍이 적용됩니다.

### 9. 텍스트 기반 컷 편집 (블로 방식)
- **`✂ 컷편집`** 탭에서 대본 단어를 눌러 고르면 그 구간의 **영상·성우·효과음·BGM이 타임라인에서 실제로 잘려 나가고**(리플 컷) 뒤 클립이 앞으로 당겨집니다.
- 줄마다 **`문장 컷`**, 자막·성우가 없는 구간을 찾아 **`무음 구간 일괄 자르기`**(0.4/0.6/1초 기준, 양쪽 120ms 여백)도 있습니다.
- 잘린 만큼 **자막 글자도 함께 잘립니다** — 남는 구간과 글자를 원본 기준으로 한 번에 계산해 여러 번 잘라도 대본과 시간이 어긋나지 않습니다. 번역문은 비율로 나누며 가까운 띄어쓰기에 맞춥니다.
- 컷은 `⌘/Ctrl+Z`로 되돌릴 수 있습니다.

### 10. 내보내기
- 해상도 1080p/720p/480p, 구간 지정, **−14 LUFS 근사 노멀라이즈**, **자막 번인** 토글.
- **MediaRecorder → WebM 실제 파일 생성**: 캔버스 30fps 캡처 + Web Audio 출력(**성우·효과음·BGM**)을 함께 담고 진행률을 보여 줍니다. 내보내기 전에 아직 없는 성우·효과음 오디오를 먼저 생성하고, 화면 시계를 오디오 시작 시각에 맞춰 영상과 소리를 정렬합니다.
  - 브라우저 음성(Web Speech)으로 떨어진 클립만 파일에 담기지 않으며, 완료 안내에 몇 개가 제외됐는지 표시합니다.
- **현재 프레임 PNG** 저장.

### 11. 프레이밍·컷이 내보내기에 반영
- WebM·PNG 렌더러가 프리뷰와 같은 함수(`lib/renderer.ts`)를 쓰므로 **비율별 프레이밍과 텍스트 컷 결과가 그대로 파일에 담깁니다**.

  Preview.tsx           캔버스 프리뷰 · 재생 컨트롤 · 비율/안전영역
  Timeline.tsx          5트랙 타임라인 (이동·트림·분할·스냅·줌)
  ExportModal.tsx       WebM · PNG · SRT
  panels/               Media · Subtitle · Script(컷편집) · TTS · SFX
lib/
  types.ts data.ts      모델 · 프리셋 · 샘플 프로젝트
  editor-context.tsx    상태·실행취소·재생 루프(시간 스토어 분리)·자동 저장
  persist.ts            IndexedDB 프로젝트·업로드 파일 저장/복원
  editor-ops.ts         분할·트림·이동·덕킹·프레이밍·리플 컷 계산
  renderer.ts           캔버스 렌더러(프리뷰 = 내보내기)
  sfx.ts audio-engine.ts Web Audio 합성·BGM·덕킹
  tts.ts                Web Speech 낭독·길이 추정
  srt.ts                SRT 생성·다운로드

## 환경변수 (선택)

| 이름 | 효과 |
| --- | --- |
| `ELEVENLABS_API_KEY` | 성우·효과음이 ElevenLabs 신경망 API로 전환 (`ELEVENLABS_VOICE_ID` 선택) — Vercel Production에 등록되어 있어 배포본은 자동으로 `provider: "elevenlabs"` |
| `OPENAI_API_KEY` | 성우가 OpenAI TTS로, 번역이 GPT로 전환 (`OPENAI_TTS_VOICE`, `OPENAI_TEXT_MODEL` 선택) |

키가 없으면 전부 브라우저 안에서(Web Speech + Web Audio + 표본 사전) 동작합니다. 결제·유료 플랜은 쓰지 않습니다.

## 개발

```sh
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
